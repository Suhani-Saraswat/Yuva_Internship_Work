# Task 3 – Integrating JavaScript for Interactive User Experience

## Project
Interactive Task Manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add tasks with input validation
- Prevent duplicate tasks
- Mark tasks as completed
- Delete individual tasks
- Filter All / Active / Completed tasks
- Clear completed tasks
- Clear all tasks with confirmation
- Dark/Light mode
- LocalStorage persistence
- Responsive layout

## How to Run
Open `index.html` in any modern web browser.

## Technologies
HTML5, CSS3, JavaScript (DOM, Events, LocalStorage)
